# 酮行 · 生酮患者管理台

面向生酮营养师 / 患者管理的轻量工具：**筛查 → 方案 → 随访 → 报告**。

## 模块

1. **患者**：建档，支持儿童癫痫 / 成人超重肥胖两条路径。
2. **筛查**：绝对禁忌 / 相对禁忌，绝对禁忌会拦截方案生成。
3. **方案**：目标能量 + 蛋白质 + 比例（3:1 / 4:1 / MAD）→ 三大营养素、餐次分配。成人 BMI≥30 时按调整体重计算蛋白。
4. **食物**：65 种常见食物碳水参考，支持分类和搜索，标出隐形碳水。
5. **随访**：血酮、血糖、体重、发作、依从性、不良反应；趋势图 + 红黄绿灯。
6. **报告**：医生版（数据） / 家长版（说人话），可打印 / 存 PDF。

## 本地运行

项目是纯静态页面，无构建步骤：

```bash
# 任选一个静态服务器
npx serve .
# 或
python -m http.server 8790
```

打开 `http://127.0.0.1:8790/`。

## 演示数据

首次打开会自动载入「案例 A · 6 岁癫痫患儿」。
右上角可切换：
- 案例 A：儿童癫痫，3:1
- 案例 B：成人超重，MAD

点「新建」开始空白患者。

## 数据

所有数据保存在浏览器 `localStorage`，键名 `keto-care-v1`，不上传服务器。

## 部署

可放到任意静态托管。GitHub Pages 示例：把本目录放到仓库子目录 `keto-care/`，访问
`https://<username>.github.io/<repo>/keto-care/`。

## 边界

- 输出是营养管理建议，不是诊断或处方。
- 具体比例、能量、监测频率需医生 / 临床营养师确认。
- 食物碳水为约值，实际以称重和营养标签为准；净碳水需另扣膳食纤维。
